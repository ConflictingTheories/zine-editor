4 · Browser Extension Hook

Auto-decryption API
Extension Integration

The gate element emits standard DOM events. A browser extension can intercept sovereign:locked events, check a local token store, and auto-present matching tokens — giving seamless auto-decryption for authorised users without any UI interaction.

Extension pattern (content script):

document.addEventListener('sovereign:locked', async (e) => {
  const { gateId } = e.detail;
  const token = await localStore.getTokenForGate(gateId);
  if (token) e.target.dispatchEvent(new CustomEvent('sovereign:present',
    { detail: { tokenJSON: token }, bubbles: false }));
});

The gate handles verification + decryption automatically. The extension never touches plaintext.
